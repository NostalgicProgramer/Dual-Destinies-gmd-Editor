English:
This is an editor for *Dual Destinies* .gmd files, created in Godot 4.4.1 using onepiecefreak's conversion code as a base.

Link: https://github.com/onepiecefreak3/GMDConverter

To use the tool, download Godot Engine version 4.4.1, open the project within it, and simply press F6 to run the program.
